# Canvas ComfyUI Remote v1.1.1 安全与隐私审计

审计日期：2026-08-01

本记录覆盖 v1.1.1 源代码、Git 历史、Android APK、Windows 安装程序、Windows 便携包及打包后 Gateway 的运行行为。该记录用于说明本次实际执行的检查，不构成第三方安全认证。

## 结论

- 最终 APK 不包含任何预置提示词、提示词分组、提示词草稿或用户本地保存内容；全新安装时，各提示词模块均为空。
- v1.1.0 中曾包含的 12 条内置角色提示词及“蔚蓝档案”分组已从源码和最终 APK 中移除。
- APK 和 Windows 便携包中未发现运行期配置、收藏、结果、日志、配对状态、私人路径、私人设备地址、账号邮箱或历史配对码。
- Gateway 打包后仅监听 `127.0.0.1`；`/web` 不提供网页端，未配对访问受保护 API 时返回 `401`。
- Android APP、Gateway 源码、首次安装、覆盖升级和卸载流程均通过自动测试。
- Python 运行、构建、开发依赖及 Android 生产依赖未发现已知漏洞。
- Gitleaks 对 Git 历史和当前工作区的扫描未发现密钥泄露。
- Microsoft Defender 对最终发布目录的自定义扫描未发现威胁。
- Android APK 已使用项目发布证书签名；Windows 安装程序尚未使用 Authenticode 商业代码签名证书。

## 发布物校验

每次正式构建均在发行目录生成 `SHA256SUMS.txt`。下载后应使用该文件核对 APK、ZIP 和安装程序。仓库发行页上传的四个文件均应来自同一次构建。

```text

```

## 数据流与隐私边界

- 生图提示词、输入图和生成结果在 Android APP、Tailscale 私网、Gateway 与本机 ComfyUI 之间传输；Canvas 不提供自建云端后台或遥测服务。
- 使用 Danbooru 搜索时，搜索标签和所请求的 Danbooru 图片地址会发送给 Danbooru；配置代理后，该部分流量还会经过所配置的代理。
- 提示词、设置、收藏、配对状态和外部 API Key 保存在用户自己的设备或本机 `%APPDATA%\CanvasGateway`。这些数据没有额外进行磁盘加密，依赖 Android 与 Windows 账号权限保护。
- 安装程序不会安装或重新配置 Tailscale，不会启用 Funnel，也不会修改 Windows 防火墙。
- 安装程序升级不会覆盖个人数据；卸载时默认保留个人数据，仅在用户明确确认后才会删除。

## 已知限制

- Windows 安装程序与 Gateway EXE 未使用 Authenticode 证书签名，Windows 可能显示“未知发布者”。应仅从项目发行页下载并核验 `SHA256SUMS.txt`。
- 本项目定位为个人使用工具，不是经过加固的多租户服务。Windows 账号、Tailnet 成员设备或代理服务一旦失陷，Canvas 无法提供额外隔离。
- 漏洞数据库和恶意软件特征会持续更新；“本次未发现”不表示未来永远不存在风险。
