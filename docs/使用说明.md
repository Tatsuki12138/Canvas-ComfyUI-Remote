# Canvas APP版使用说明

本说明对应APP-only开源版。它没有网页生图页面，也不会启用Tailscale Funnel。

## 一、工作方式

Canvas由两个程序组成：

1. 电脑上的Canvas Gateway负责读取工作流、调用ComfyUI、转发Danbooru请求和把图片传给手机。
2. 安卓APP负责编辑参数、提示词、浏览结果和控制电脑上的ComfyUI。

手机和电脑需要登录同一个Tailscale网络。APP里虽然显示的是`http://...ts.net:3001`，流量仍然位于Tailscale的加密隧道中；Gateway和ComfyUI本身只监听电脑回环地址。

## 二、准备工作

电脑需要：

- Windows 10或Windows 11
- Python 3.10、3.11或3.12
- 已经能够正常运行的ComfyUI
- Tailscale客户端

手机需要：

- Android 6.0或更高版本
- Tailscale客户端
- Canvas APK

先确保电脑和手机上的Tailscale登录同一账号或同一个Tailnet，并且两台设备均显示在线。

## 三、安装Gateway

### 推荐：Windows安装向导

下载并运行`Canvas-Gateway-Setup-v1.1.1.exe`：

1. 选择Canvas Gateway安装位置，默认无需管理员权限；
2. 选择包含`main.py`的ComfyUI目录；
3. 确认自动识别到的ComfyUI Python；
4. 电脑访问Danbooru需要代理时填写代理地址，否则留空；
5. 按需勾选桌面快捷方式和开机启动，开机启动默认关闭；
6. 安装完成后打开Canvas控制中心。

安装程序不会安装ComfyUI或Tailscale，不会修改Windows防火墙，也不会启用Tailscale Funnel。它只将Canvas程序安装到当前用户目录，并把配置保存到`%APPDATA%\CanvasGateway`。

公开版暂未使用商业代码签名证书，因此Windows可能显示“未知发布者”。请只从本仓库发行页下载，并用`SHA256SUMS.txt`校验SHA-256。

### 绿色便携版

下载`Canvas-Gateway-Windows-v1.1.1.zip`并解压，双击`First-Run-Setup.cmd`，选择包含`main.py`的ComfyUI目录即可。发行包已经包含Gateway程序，不需要为Gateway另装Python；选择的Python是ComfyUI自身运行所需的环境。

### 升级和卸载

- 直接运行新版安装器即可覆盖升级；
- 升级只更新程序文件，不覆盖现有配置、提示词、收藏或配对状态；
- 卸载时默认保留`%APPDATA%\CanvasGateway`；
- 只有在卸载提示中明确选择删除，个人数据目录才会被移除；
- 开始菜单中的“配置Canvas Gateway”可重新选择ComfyUI路径，它不会删除提示词和收藏。

### 从源码运行

解压源码或发行包后，在项目根目录打开PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup-gateway.ps1
```

首次运行会弹出目录选择窗口。请选择包含`main.py`的ComfyUI目录。

脚本会尝试识别常见环境：

- 秋叶整合包相邻的`python\python.exe`
- ComfyUI相邻或内部的`python_embeded\python.exe`
- `venv\Scripts\python.exe`
- `.venv\Scripts\python.exe`

如果没有识别成功，可以手动指定：

```powershell
.\scripts\Configure-Canvas.ps1 `
  -ComfyUIPath "D:\AI\ComfyUI" `
  -ComfyPython "D:\AI\python_embeded\python.exe" `
  -Force
```

配置保存于：

```text
%APPDATA%\CanvasGateway\config.json
```

升级源码不会覆盖这个目录。

## 四、启动与配对

双击：

```text
Canvas-Control-Center.cmd
```

点击“启动Canvas”。控制中心会：

1. 启动本机Gateway；
2. 检查Tailscale状态；
3. 在Tailnet内建立3001端口入口；
4. 显示APP URL和八位配对码。

在手机APP中填写：

- Gateway URL：控制中心显示的完整地址，例如`http://your-pc.example.ts.net:3001`
- Pairing Code：控制中心显示的八位数字

配对码有效期为30分钟。过期后重启Gateway即可生成新配对码。

## 五、日常使用

每次使用前：

1. 确认电脑和手机的Tailscale在线；
2. 打开Canvas控制中心；
3. 点击“启动Canvas”；
4. 在APP设置页启动ComfyUI，或提前手动打开ComfyUI；
5. 进入Create页面生成图片。

停止Canvas不会停止Tailscale，也不会停止ComfyUI。控制中心只关闭Gateway和Canvas使用的3001端口入口。

## 六、提示词与设置备份

APP设置页提供：

- Export Backup：导出提示词和设置备份；
- Import Backup：导入备份。

备份包含：

- 提示词模块、预设和分组；
- LoRA选择；
- 工作流选择；
- 各工作流底模选择；
- 各工作流负面提示词。

备份不包含Gateway URL、配对令牌或外部API Key。导入前建议保留一份旧备份。

## 七、Danbooru与代理

Danbooru请求由电脑Gateway发出，手机不需要单独连接代理。

需要代理时，编辑：

```text
%APPDATA%\CanvasGateway\config.json
```

例如：

```json
"proxy_url": "http://127.0.0.1:7890"
```

修改后重启Gateway。代理只应填写你信任的本机代理地址。

Danbooru搜索词会发送到Danbooru服务；这是搜索功能正常工作所必需的。生图正向/负向提示词、ComfyUI输入图和生成结果不会发送给Danbooru。配置第三方代理后，Danbooru流量还会经过该代理，因此只能使用可信代理。

## 八、WD14反推

WD14功能要求ComfyUI安装支持`WD14Tagger|pysssss`的自定义节点和对应模型。APP设置页会显示检测结果。

如果提示缺少`character_threshold`、`exclude_tags`或图片无效，请先升级对应的ComfyUI节点，再重启ComfyUI和Gateway。

## 九、工作流

仓库附带的工作流模板只是API格式模板，不包含模型。每个工作流通过节点映射告诉Gateway应修改哪些输入。

自定义工作流方法参见[自定义工作流封装指南.md](%E8%87%AA%E5%AE%9A%E4%B9%89%E5%B7%A5%E4%BD%9C%E6%B5%81%E5%B0%81%E8%A3%85%E6%8C%87%E5%8D%97.md)。该文档同时包含人工操作步骤、参数映射表、第三方节点注意事项，以及可直接交给其他AI使用的任务模板。节点编号变化后必须同步更新映射，否则ComfyUI会拒绝工作流或参数不会生效。

## 十、常见故障

### APP无法连接

依次检查：

1. 电脑和手机Tailscale是否在线；
2. 控制中心的APP私网入口是否开启；
3. URL是否包含`http://`和`:3001`；
4. 手机是否安装了会接管全部VPN流量的其他软件；
5. 点击控制中心“修复连接”；
6. 查看`%APPDATA%\CanvasGateway\logs`。

### Gateway启动失败

重新运行：

```powershell
.\scripts\Configure-Canvas.ps1 -Force
```

确认所选目录包含`main.py`，并且配置的Python能够启动该ComfyUI。

### 工作流被拒绝

通常是模型文件名、节点类型或节点编号与模板不一致。先在ComfyUI网页中手动运行同一工作流，再根据错误安装节点或调整配置。

### 生成完成但图片未显示

不要立即关闭Gateway。检查ComfyUI输出目录是否与`config.json`中的`comfy_output_dir`一致，然后查看Gateway日志。

## 十一、安全注意事项

- 不要把3000或8188端口映射到公网；
- 不要启用Tailscale Funnel来发布本项目；
- 不要分享配对码、Bearer Token或外部API Key；
- 不要把`%APPDATA%\CanvasGateway`上传到GitHub；
- 使用外部API后如怀疑Key泄露，应立即在APP设置页轮换Key。

Canvas没有遥测或Canvas托管服务器。Gateway只会连接本机ComfyUI和用户主动使用的Danbooru；Tailscale负责手机与电脑之间的私网入口。个人数据没有额外的磁盘加密，安全边界是Windows账号、Android应用沙箱和Tailnet成员权限。
